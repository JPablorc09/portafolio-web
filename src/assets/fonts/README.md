Fuente Inter utilizada previamente mediante Google Fonts; se conservan los subconjuntos Latin y Latin Extended, con pesos variables 400–700 y `font-display: optional`. Licencia SIL Open Font License incluida en OFL.txt.

Origen: https://fonts.google.com/specimen/Inter

Archivos descargados el 27 de octubre de 2026 desde fonts.gstatic.com, versión de distribución v20. La licencia procede de https://github.com/google/fonts/tree/main/ofl/inter. No se modificaron los archivos de fuente.

La política optional permite usar la tipografía del sistema durante una primera visita lenta, evitando una sustitución tardía que desplace el contenido. Los archivos Inter siguen disponibles localmente para cargas rápidas y visitas posteriores.
